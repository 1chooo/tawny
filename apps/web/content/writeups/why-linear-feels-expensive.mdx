An issue list feels expensive when a few defaults stay put. The five below are the ones in Design Motion's walkthrough of Linear: density, hairline borders, a single chrome color, visible shortcuts, and a 4px grid. Apply them in that order. Each decision stays in place when the next one arrives.

The figure uses one viewport and the same fourteen issues. **Before** fits eight rows at 56px. After density, all fourteen fit at 32px. Later steps only change surface, color, input, and alignment.

## Density

Set the row to 32px, the type to 13px, and the letter-spacing to `-0.01em`. The shorter row is what buys the extra six issues. The tighter tracking keeps 13px type from looking sparse. Use one row height for the whole list so the scan line stays even.

On any list, choose the row height from how many records should be on screen, then fit the type to that height. 32px and 13px is the pair this list uses.

## Borders

Separate the screen with three backgrounds and a 1px line of white at 8% opacity. Hover paints the next surface in the stack. The shadow on the panel stays off.

| Token | Value |
| --- | --- |
| Canvas | `#0B0D10` |
| List surface | `#13161B` |
| Hover surface | `#1A1E25` |
| Border | `1px solid rgba(255, 255, 255, 0.08)` |

```css
box-shadow: none;
background: #13161b;
border: 1px solid rgba(255, 255, 255, 0.08);
```

Hover sets the row to `#1A1E25`. Treat elevation as a background step in the same ramp, including the sidebar and the panel around the list.

## One color

Spend indigo `#5E6AD2` in two places: the selected row and the primary button. Status is a grey icon — an open circle, a half-filled circle, or a check. Priority and labels are grey text in the same neutral.

A list still has to show state. It can do that with a shape. Write down the one chrome color and the two components allowed to use it, and keep status hues out of the row.

## Keyboard

Print the shortcut on the control that runs it. Filter is `F`, Display is `D`, New issue is `C`, and search is `⌘K`. Hover feedback lands in about 80ms. Other transitions stay at or under 150ms, on an ease-out curve, with no overshoot.

```css
transition: background-color 80ms cubic-bezier(0.25, 0.46, 0.45, 0.94);
```

Open the command palette in the figure. The same rule is listed there: `P` sets priority, `I` assigns the issue to you, `⌘B` toggles the sidebar. If an action has a shortcut, the shortcut is part of the label. Put the durations in the same token file as the colors.

## Alignment

Lock spacing to a 4px grid. Draw the status icon at 16px and center it on the text line. Keep the id and the title on the left. Give the label, the initials, and the date fixed tracks on the right.

```css
grid-template-columns: 16px 3.5rem minmax(0, 1fr) auto auto auto;
gap: 8px;
padding-inline: 8px;
```

When those tracks line up, the alignment disappears into the list. A date that drifts is the first thing the eye catches, so the right edge is the one to check.

## Do and don't

Do:

- Build depth from three background values plus a hairline border at 8% white, and change the surface value on hover.
- Print the keyboard shortcut next to every action. Keep hover near 80ms and other transitions under 150ms.
- Left-align labels and ids, right-align numbers and dates, and center 16px icons on the text line.

Don't:

- Use a drop shadow to separate rows, panels, or the sidebar.
- Encode status or priority with a colored pill when a grey icon carries the same meaning.
- Let a transition bounce, overshoot, or run past 150ms.
