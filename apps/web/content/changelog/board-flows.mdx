Board is no longer a static issue list. The sidebar, filter, display, and commands each change what you see.

<ChangelogPreview id="issue-list" />

## A short loop

Inbox, My issues, Issues, and Backlog filter the rows. Filter narrows by status. Display switches between the aligned list and a Todo / In progress / Done board. Selecting a row opens its detail, where status is a control.

New issue, and the Create issue command, add a row from a title. Assign to me, search, and the sidebar toggle do what they say. The bell opens two notices.

### Improvements

- Sidebar views filter the issue list
- Filter narrows by Todo, In progress, and Done
- Display switches between the list and a three-column board
- A detail pane updates status, and New issue adds a row
- Command palette actions and the bell are clickable
