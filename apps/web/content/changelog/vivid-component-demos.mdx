Component detail pages now use a tall stage, the same scale as the issue list, so a navbar, a button, or a map reads at real size instead of a thin strip. Gallery cards crop tighter around that subject.

<ChangelogPreview id="dotted-map" />

## The map follows the theme

Land dots use the foreground at 70% — ink on cream in light, paper on ink in dark — instead of a fixed gray faded to 40%. Markers stay tawny.

### Improvements

- Raised the default component detail frame to a 36rem stage
- Cropped header, motion, and effects gallery cards around the subject
- Painted dotted-map dots with the theme foreground
