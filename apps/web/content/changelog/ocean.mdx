Ocean is a scroll-driven WebGL landing page. A particle whale, sea turtle, jellyfish, and manta ray — each sampled from a glTF model — morph into one another as you scroll.

<ChangelogPreview id="ocean" />

## Dive through the creatures

Ocean is a single-page studio landing built around a Three.js particle field. Each creature is a glTF model sampled into the same number of points, and a custom shader morphs between them as you scroll, with ocean currents, bioluminescent shimmer, and a cursor ripple layered on top.

Scroll the live demo to dive through all four creatures, or scaffold a copy and swap in your own studio copy.

```bash
npx create-tawny@latest --template ocean
```
